# Release Checklist

Use this before the first public launch.

## Repo Readiness

- [ ] README first screen explains the value in one sentence.
- [ ] Demo SVG or GIF renders in GitHub.
- [ ] `npm test` passes.
- [ ] `npm run scan` produces a clear report.
- [ ] `npm run fix` previews review-marked JSON changes without writing files.
- [ ] GitHub Action example is copied into README and `.github/workflows/`.
- [ ] Before/after examples cover vague descriptions, missing parameter semantics, and destructive tools.
- [ ] `pr --create` remains documented as an explicit live GitHub side effect.

## Proof Readiness

- [ ] At least 5 real MCP ecosystem PRs opened.
- [ ] At least 2 PRs merged or discussed seriously.
- [ ] PR target table updated.
- [ ] Scan report drafted from real findings.
- [ ] Launch copy includes caveats and avoids safety guarantees.

## Launch Channels

- [ ] Hacker News `Show HN`.
- [ ] Reddit `r/mcp`.
- [ ] Reddit `r/LocalLLaMA`.
- [ ] MCP Discord.
- [ ] X / LinkedIn.
- [ ] V2EX.
- [ ] Product Hunt after usage exists.
